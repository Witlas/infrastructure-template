# Security Policy

## Reporting a vulnerability

Please do not open public issues for suspected vulnerabilities.

Report security issues privately to the repository maintainers through GitHub Security Advisories or a private communication channel agreed by maintainers.

Include:

- Description of the issue
- Potential impact
- Steps to reproduce
- Suggested remediation (if known)

## Secret handling expectations

- Do not commit plaintext credentials or private keys.
- Use encrypted secret files and secure secret stores.
- Rotate any credential immediately if exposure is suspected.
