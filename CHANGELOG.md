# Changelog

All notable changes to this template are documented in this file.

## [0.1.0] - 2026-09-21

### Added

- Initial public infrastructure template release.
- GitHub Actions CI for shell, YAML, and Ansible validation.
- Pull request and issue templates for public collaboration.
- `secrets/README.md` documenting safe secret-handling expectations.

### Changed

- Expanded README with template usage, validation commands, and security checklist.
- Hardened script checks for missing `.env` and placeholder credentials.
- Updated `.gitignore` for local secret/state/backup artifacts.
